# ShoeStore — Магазин обуви
Учебный проект: десктопное приложение для автоматизации учета товаров и заказов.
## Возможности
- Просмотр каталога обуви
- Поиск и фильтрация товаров
- Оформление заказов
## Требования
- Python 3.9+
- PostgreSQL 13+
## Установка и запуск
1. Клонировать репозиторий.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Скопировать `config.py.example` в `config.py` и указать свои параметры подключения.
4. Запустить приложение: `python main.py`.
