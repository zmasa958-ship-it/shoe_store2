# ShoeStore — Магазин обуви
Учебный проект: десктопное приложение для автоматизации учета товаров и заказов.
## Возможности
- Просмотр каталога обуви
- Поиск и фильтрация товаров
- Оформление заказов
## Требования
- Python 3.9+
- PostgreSQL 13+
## Установка и запуск
1. Клонировать репозиторий.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Скопировать `config.py.example` в `config.py` и указать свои параметры подключения.
4. Запустить приложение: `python main.py`.

## Запуск PostgreSQL через Docker Compose

Проект использует PostgreSQL, запущенный в Docker-контейнере. Это позволяет не устанавливать СУБД на компьютер и легко управлять базой данных.

### 1. Предварительные требования и установка Docker
Для работы приложения необходима среда контейнеризации:
1. Скачайте и установите **Docker Desktop** с официального сайта: [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/).
2. При установке на Windows убедитесь, что выбрана опция **"Use WSL 2 instead of Hyper-V"** (Использовать WSL 2).
3. После установки запустите Docker Desktop и дождитесь, пока индикатор в трее не покажет статус **"Running"** (зеленый значок кита).
4. Установите **Python 3.9+** с официального сайта.
5. Убедитесь, что порт, который вы планируете использовать (по умолчанию **5433**), свободен.

### 2. Создание файла .env
Для запуска базы данных необходимо создать локальный файл конфигурации:
1. В корне проекта найдите файл `.env.example`.
2. Создайте его копию и переименуйте в `.env`.
3. Откройте `.env` в текстовом редакторе и замените значение `POSTGRES_PASSWORD` на свой надежный пароль (например, `qw1`).
4. **Важно:** Если порт `5433` уже занят на вашем компьютере, вы можете изменить его на любой свободный порт в строке `POSTGRES_HOST_PORT`.
   *Пример содержимого:*
   ```text
   POSTGRES_DB=shoe_store
   POSTGRES_USER=postgres
   POSTGRES_PASSWORD=qw1
   POSTGRES_HOST_PORT=5433
